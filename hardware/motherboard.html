主板与机箱规格对照

  • ▶Intel 平台（LGA 插槽）

    H610 — 入门级

    内存DDR4/DDR5
    CPU 超频不支持
    内存 XMP 超频不支持

    B760 — 主流

    内存DDR4/DDR5
    CPU 超频不支持
    内存 XMP 超频支持

    Z790 — 旗舰

    内存DDR5
    CPU 超频支持
    内存 XMP 超频支持（高频率上限更高）
    总结：Intel 只有 Z 板支持 CPU 超频。H610 和 B760 不可超 CPU，但 B760 可内存 XMP。
  • ▶AMD 平台平台（AM4 / AM5）

    A620 — 入门 (AM5)

    内存DDR5
    CPU 超频不支持
    内存 EXPO 超频支持

    B650 / B650E — 主流

    CPU 超频支持
    内存超频支持
    B650E 独有PCIe 5.0 x16 槽

    X670 / X670E — 旗舰

    CPU 超频支持
    内存超频支持（上限更高）
    X670E 独有两个 PCIe 5.0 x16 槽
    总结：AMD B650/X670 系列都支持 CPU 超频。A620 不支持。两个平台都是主流级以上可内存超频。
  • ▶主板后缀含义
    后缀含义举例
    -MMicro-ATX 小板型H610M-K
    -K华硕低配型（接口少、用料精简）H610M-K
    -A标注更多视频输出接口（华硕）H610M-A
    -E基础入门版，接口较少（华硕）H610M-E
    -F无板载核显输出接口（华硕）B760M-F
    -Plus / -Pro中档，接口多/供电加强B760-Plus
    -TUF / -ROG高端游戏系列——更强的供电与散热B760M-TUF

    例：H610M-K = H610 + Micro-ATX 小板 + 减配版。 B760M-A WiFi = B760 + M-ATX + A多接口 + WiF/蓝牙。

  • ▶带 WiFi 和不带 WiFi 的区别

    📡 带 WiFi 版本

    识别型号末尾有 "WiFi" 或 "AC/AX"
    优点板载无线网卡 + 蓝牙模块，无需额外 PCIe 卡。适合没网线或蓝牙设备多（手柄/耳机）
    缺点比不带WiFi版贵 50-100 元，需要外接天线

    🔌 不带 WiFi 版本

    识别没有 WiFi 字样
    优点价格低，不需要天线
    注意只能靠网线联网。想用蓝牙必须另买 USB 蓝牙适配器或 PCIe 网卡。
    后装方案：已有不带 WiFi 的主板？买一个 PCIe x1 WiFi6 模块（AX210 约 60 元）插上去，蓝牙和 WiFi 就都有了。
  • ▶主板尺寸规格（从小到大）

    Mini-ITX（170mm × 170mm）

    内存2
    PCIe1 x16
    适用极小机箱/便携主机

    Micro-ATX（244mm × 244mm）

    内存2-4
    适用90% 家用装机

    Standard ATX（305mm × 244mm）

    内存4
    适用旗舰游戏/多扩展卡

    Extended-ATX（305mm × 277mm+）

    更宽——必须用 E-ATX 兼容机箱。工作站。

  • ▶机箱规格对照

    ITX 机箱

    主板仅 Mini-ITX
    显卡180-300mm
    散热120mm 冷
    电源SFX

    M-ATX 机箱

    主板ITX + M-ATX
    散热240/280 冷排
    电源ATX

    ATX 中塔

    主板ITX/M-ATX/ATX
    散热360 冷排
    体积约微波炉

    E-ATX 全塔

    主板所有含 E-ATX
    体积巨大
    装机先检查：ITX/M-ATX/ATX 主板尺寸 + 显卡长 + 电源长 + 冷排安装位
