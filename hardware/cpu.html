CPU 处理器详解

  • ▶Intel 英特尔
    • ▶酷睿 (Core) 桌面系列

      i3 — 入门 / 轻办公

      核心/线程4 Core / 8 Thread
      适用 |

      i5 — 主流性能

      核心/线程10-14 Core（混合架构）
      适用中大型游戏 + 轻创作

      i7 — 高端多任务

      核心/线程16-20 Core
      适用视频剪辑 / 3D 建模

      i9 — 旗舰极限性能

      核心/线程24 Core / 32 Thread
      适用重度多线程、工作站
    • ▶Core Ultra 系列 — 新命名体系 (2024+)

      Core Ultra 5 / 7 / 9

      架构Meteor Lake（分离式 tile 设计） + Arrow Lake
      工艺Intel 4 + TSMC 3nm
      亮点首次内置 NPU（AI 加速单元）、新一代 SoC 架构、能效比大幅改善
      命名示例Core Ultra 7 265K（Arrow Lake）

      从第14代开始，Intel 不再用 "i" 前缀——所有新处理器改为 Core Ultra 5/7/9 或 Core 3/5/7 命名。

    • ▶奔腾 (Pentium) / 赛扬 (Celeron)

      定位

      低功耗办公/教育用途，迷你主机或软路由常用。

    • ▶至强 (Xeon)

      定位

      服务器/工作站级，支持 ECC，不支持常规游戏 PC。

  • ▶AMD 超威
    • ▶锐龙 (Ryzen) 系列

      Ryzen 3 — 入门

      代表R3 4100, R3 5300G
      适用家庭日常、网课

      Ryzen 5 — 主流甜点

      代表R5 5600, R5 7500F, R5 7600, R5 9600X
      适用游戏 + 轻创作

      Ryzen 7 — 高效多核

      代表R7 5800X, R7 7700X, R7 7800X3D, R7 9800X3D
      适用游戏直播 / 渲染引擎

      Ryzen 9 — 桌面旗舰

      代表R9 5950X, R9 7950X, R9 9950X
      适用3D 动画 + 科学计算多线程
    • ▶APU（板载核显系列）

      定位

      带 Radeon Graphics 核心显卡，适合 ITX 和无独显迷你机。

    • ▶Threadripper 线程撕裂者

      定位

      64 核专业工作站/虚拟多开，需搭配 TRX50 芯片组。
