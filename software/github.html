实用开源项目精选

  • ▶AI 与本地大模型

    🧠 LM Studio — 图形化本地大模型管家

    带桌面窗口的本地大模型应用，无需命令行。下载模型、选模型、对话全在一个界面，支持 GGUF 量化模型。

    🔗 lmstudio.ai（Windows/Mac/Linux）

    🎨 Stable Diffusion WebUI — 本地 AI 画图

    浏览器里输入描述词出图，插件生态最全。GPU 8GB+ 显存体验最佳。

    🔗 github.com/AUTOMATIC1111/stable-diffusion-webui

    🔮 ComfyUI — 节点式 AI 作图工作流

    拖拽节点连线构建出图流程，LoRA、ControlNet、高清修复全在画布上看得见。

    🔗 github.com/comfyanonymous/ComfyUI

    🎵 GenP — Adobe 套件补丁

    让 Adobe 全家桶本地完整使用的开源补丁，详细介绍见「GenP 与 Adobe 套件」页。

    🔗 github.com/SpoinkyNL/GenP-3

  • ▶系统与效率

    🌲 PowerToys — 微软官方增强套件

    取色器、FancyZones 窗口分区、批量重命名、键盘重映射，装机必装。

    🔗 github.com/microsoft/PowerToys

    📁 EverythingToolbar — 任务栏全盘秒搜

    把 Everything 的秒级文件搜索嵌进 Windows 任务栏。

    🔗 github.com/srwi/EverythingToolbar

    🧩 ImHex — 十六进制编辑器

    查看二进制文件内部结构，带解析器，修复损坏文件用得着。

    🔗 github.com/WerWolv/ImHex

    🔊 OBS Studio — 免费直播/录屏

    开源直播录制标准，多场景 + 推流各大平台。

    🔗 github.com/obsproject/obs-studio

    🛠 图吧工具箱 — 硬件检测合集

    CPU-Z、GPU-Z、AIDA64、CrystalDiskMark 全打包，装机检测一站式。

    🔗 www.tbtool.cn
