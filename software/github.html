GitHub — 全球最大的开源代码平台

  • ▶GitHub 是什么

    GitHub 是微软旗下的全球开源代码托管社区。几乎所有知名开源项目都在上游一个仓库 (repository) 维护。对于学 AI、网页开发的同学来说，这是最可靠的无偿学习资源源——你不需要会写代码也能在浏览自述文件时获益。

  • ▶核心操作

    Star（收藏）

    喜欢的项目加一颗星标，方便以后回看。

    Fork（叉一叉）

    把别人的仓库克隆到你自己的账号，自由修改。

    Pull Request (PR)

    你修改后向原作者提交改动请求——开源贡献的核心流水线。

    Issues

    报告 Bug、请求新特性、与作者团队讨论。

  • ▶怎样发现好资源
    1. 搜索带大量 Star 的仓库，awesome-* 专题汇总——比如 awesome-python/awesome-llm。
    2. 找持续维护（近期多次 commit）的社区。
    3. 关注你所在领域的 GitHub Organization 页面。
  • ▶GitHub Pages — 免费静态网站

    仓库名设成 你的GitHub名.github.io 就自动变成全球可用的个人网页。你只需上传 HTML/CSS 文件。

  • ▶精选开源项目推荐

    🎵 GenP — Adobe 激活补丁

    GenP 是一个面向 Adobe Creative Cloud 套件的开源补丁工具，可让用户在本地不依赖官方许可证登录的系统，仍然体验到 Photoshop、Premiere、AE 等全部功能。对想学习创意设计又没有购买预算的学生群体是一个很好的学习素材。

    🔗 https://github.com/SpoinkyNL/GenP-3

    🧠 LM Studio — 图形化本地大模型管家

    和 Ollama 功能类似但提供带桌面窗口的简易应用——无需任何命令行操作。下载模型、选模型、开始对话都可以在一个界面里完成。支持 llama.cpp 作为后端加载，支持使用 GGUF 格式的量化模型，很耐用。

    🔗 https://lmstudio.ai （＜官网｜Windows/Mac/Linux 全支持）

    🎨 Stable Diffusion WebUI — 本地 AI 画图（浏览器版）

    在浏览器窗口输入描述词，自动渲染图像。只需下载及其脚本即可。GPU 8+ GB 体验最优。

    🔗 https://github.com/AUTOMATIC1111/stable-diffusion-webui

    🔮 ComfyUI — 节点式 AI 作图工作流

    相对于上面的 WebUI，ComfyUI 通过自由拖拽节点连线构建 AI 出图流程。想用 LoRA、ControlNet、高清修复、一系列返回回路？全在画布上看得见。适合想要 DIY 出图流程的使用者。

    🔗 https://github.com/comfyanonymous/ComfyUI

    🛠 图吧工具箱 — 电脑硬件检测合集

    图吧工具箱是国内电脑硬件党必备的一站式检测套件。内置 CPU-Z、GPU-Z、AIDA64、CrystalDiskMark（录像/硬盘/内存综合测试）和 GPU 显卡烤机工具。所有都打包好，不用单独下载。

    🔗 https://www.tbtool.cn

    🧩 ImHex — 十六进制文件编辑器

    查看二进制文件（exe/固件）内部构造，带解析器。修复损坏文件或发现隐藏结构用得着。

    🔗 https://github.com/WerWolv/ImHex

    🔊 OBS Studio — 免费直播/录屏/推流

    免费开源标准的直播与录制工具。支持多场景框架 + 预设推流到各大平台。

    🔗 https://github.com/obsproject/obs-studio

    📁 EverythingToolbar — 秒级全盘文件搜索

    在 Windows 任务栏嵌入微秒级的全盘文件检索在线，逐字出文件速度极高。

    🔗 https://github.com/srwi/EverythingToolbar

    🌲 PowerToys — 微软官方增强套件

    包含唤彩取色、FancyZones 窗口对齐、文本加速提取、键盘重映射等。

    🔗 https://github.com/microsoft/PowerToys
