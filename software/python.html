Python 依赖 — 装什么工具都绕不开的地基

  • ▶为什么它重要

    你不需要会写 Python，但你的电脑大概率需要装它。大量常用工具把 Python 当作运行地基（依赖）——没有它，这些软件装完根本跑不起来。这是普通用户接触 Python 的最主要原因。

    哪些工具依赖 Python

    工具 / 软件依赖 Python 的原因
    Stable Diffusion WebUI / ComfyUI整个程序就是 Python 写的，本地起 Web 服务跑 GPU 推理
    OBS 高级脚本动态控制脚本几乎都是 .py 文件
    Blender 插件插件系统基于 Python
    各类开源小工具 / 自动化脚本GitHub 上的工具十有八九要 Python 环境才能运行
  • ▶安装（一次搞定）

    下载

    官网 python.org/downloads 下载最新的 Python 3.x。

    安装时必勾

    Add Python to PATH——不勾的话命令行里认不到 python 命令，后面所有工具都会报错。

    验证

    命令行输入 python --version，显示版本号即成功；再输入 pip --version 确认包管理器也就位。

    注意：不要安装在路径带空格或中文的目录里（比如"新建文件夹"），很多依赖工具会直接报错。默认路径或 C:\Python3x 最稳。
  • ▶pip 与换源加速

    pip 是什么

    Python 的"应用商店"——工具跑起来前要装的一堆依赖包都用它安装：pip install 包名。Stable Diffusion 一键启动脚本第一次跑的时候，自动帮你执行的就是这个。

    国内换源（速度差 10 倍以上）

    官方源在国内很慢，用清华源：
    pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple
    设为默认：
    pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
