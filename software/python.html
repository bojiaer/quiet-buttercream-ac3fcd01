Python — 编程语言中的万能工具

  • ▶Python 是什么

    Python 是一种被广泛使用的高级编程语言，语法特别简单——就像用英语写指令。它不是要你成为程序员才装，很多常用软件（OBS 的脚本扩展、Blender 的插件系统、Stable Diffusion 的自动部署）都需要电脑装了 Python 才能跑。

  • ▶为什么需要 Python（依赖层面）

    很多厉害的工具依赖它

    工具 / 软件需要 Python 的原因
    Stable Diffusion / ComfyUI底层用 Python 创建一个本地 Web 服务器与 GPU 交互
    OBS 高级脚本几乎所有动态媒体控制脚本都是 .py 格式
    自动脚本化推流 / pip 自动数据需要 Python 来操作流程
    很多游戏外挂/提取文件工具subprocess 调的多数是 Python
  • ▶怎么获得

    下载安装包

    从 Python 官网 https://www.python.org/downloads/ 下载 Python 3.X 最新版本 → 安装时记得勾选 Add Python to PATH

    装好后验证

    打开命令行 -> 输入 python --version，看到版本号即成功。

    一个注意: 如果把 Python 安装在路径含空格的目录里，很多依赖工具会报错——用户文件夹
