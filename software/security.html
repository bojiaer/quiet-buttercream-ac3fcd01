  • ▶🦠 常见病毒识别与处理方法

    🦊 银狐病毒 (Silver Fox)

    传播方式通过微信/QQ/钉钉伪装成发票、合同、工资表等文档发送，实为带宏病毒的 Office 文件或伪装 .exe
    中招表现电脑远程被控、鼠标自己动、浏览器密码被窃取、凭空出现新安装的远程控制软件如 AnyDesk / TeamViewer

    怎么观察是否中招：

    1. 任务管理器 → 进程 → 按 CPU/网络排序 → 有没有叫 svchost.exe 但路径不在 C:\Windows\System32\ 下的？
    2. 打开 msconfig → 启动 → 有没有名称乱码或可疑启动项？
    3. 检查"程序和功能"中是否有突然出现的远程控制软件不是你装的。

    处理方法：

    1. 直接拔网线。
    2. 进入 Windows 安全模式（网络禁用模式）。
    3. 火绒全盘查杀 → 高启发模式扫描。
    4. 清除完成后立刻修改所有已登录过的账户密码。
    5. 银狐常留后门，重装系统是最彻底的方式。

    🐴 木马病毒 (Trojan)

    传播方式伪装成正常文件的恶意代码——游戏修改器、破解补丁、不明来源安装包
    中招表现不稳定卡顿、磁盘凭空多出新目录、随机数字命名的进程

    怎么观察：

    1. Win+R 输入 shell:startup 看启动目录里有没有不明快捷方式。
    2. 运行 netstat -ano | findstr ESTABLISHED 终端里看不认识的国外 IP 连接，记下 PID 后去任务管理器找对应进程。
    3. 打开 services.msc 查看描述为空或名字乱码的服务——直接禁用。

    怎么处理：火绒全盘+专杀扫描 → 用 Autoruns 查遍所有启动项 → 删除后清空 %temp% 和 C:\Windows\Temp。

    ⛏ 挖矿病毒 / CryptoJacking

    传播方式捆绑在盗版游戏安装包/盗版影视软件中，或通过驱动缓存自动植入
    中招表现CPU/GPU 持续 90-100% 满载导致噪声满爆——开个记事本都卡。显卡显存始终充满。

    怎么观察：

    1. 任务管理器一直 100% CPU 满载状态下有没有一个异常名字的进程。
    2. 检查计划任务程序 → 看是不是有触发器每 30 分钟启动一个新进程。
    3. 查找硬盘里找散落的 256MB+ 的整文件最小路径。

    处理：火绒开启勒索/挖矿防护→断了网→安全模式在静音查杀。

    🔒 勒索病毒 (Ransomware)

    典型症状所有文档后缀都变成 .locked / .encrypted / .wannacry 之类，桌面出现英文/中文付款救人通知。

    处理（不要慌）：

    1. 立即物理断电切断电源！阻止继续加密。
    2. 把尚未加密的一个关键文件备份到空U盘备用。
    3. 去 NoMoreRansom 项目搜索你档后缀对应的解密工具。
    4. 如果 3 小时内无救——不付款——格式化然后恢复最近镜像备份。

    📢 流氓软件 / 广告弹窗

    传播方式安装文件时跳过自定义选项偷偷捆绑装入整套软件。
    中招表现桌面多出各种加速大师、壁纸被换、浏览器跳出带货窗口。

    怎么观察 / 处理：

    1. 火绒弹窗拦截 → 找到对应可疑推广工具栏。
    2. 打开 appwiz.cpl 按安装日期倒序——能看到最后安装的入侵软件。
    3. 将陌生软件批量卸载。
    4. 以后装任何东西盯着"自定义安装"手动取消所有附带勾选。
