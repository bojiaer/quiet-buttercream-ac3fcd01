GenP — Adobe 套件的开源补丁项目

  • ▶GenP 是什么

    GenP 是 GitHub 上的一个开源补丁工具（Community-led 项目），针对 Adobe Creative Cloud 全家桶——Photoshop、Premiere、After Effects、Illustrator 等都能覆盖。它的作用是让这些软件在本地不依赖官方订阅授权即可完整使用，对想学创意设计但没有订阅预算的学生群体影响很大。

  • ▶使用前必须知道的三件事

    1. 版本必须匹配

    GenP 的每个版本只支持特定版本的 Adobe 软件（看 Releases 页面的说明）。Adobe 软件版本更新后，旧补丁通常会失效，需要等 GenP 更新或锁定 Adobe 的自动更新。

    2. 只从 GitHub 官方仓库获取

    GenP 只通过其 GitHub 仓库发布。网上第三方"下载站"经常把补丁和木马打包在一起（银狐、挖矿马的重灾区），不要碰。

    3. 杀毒软件会报毒

    补丁的工作方式决定了它会被杀软标记。这是预期行为，但前提是你确认拿到的是官方仓库的原版文件。

  • ▶对 Adobe 使用方式的改变
    方面官方订阅GenP 补丁
    费用每月订阅，价格不低免费
    账号必须登录 Adobe 账号不依赖许可证登录
    更新自动更新更新会破坏补丁，需锁定
    云服务云文档 / 字体库 / AI 功能部分云端功能不可用
