办公与编码工具

  • ▶Excel — 表格与数据处理

    Excel 就是电子表格。你可以用它记账、做名单、统计成绩。最有用的四个函数：
    VLOOKUP——在另一张表格里找匹配的数据。
    XLOOKUP——增强版查找，比 VLOOKUP 更快。
    COUNTIF——统计有多少行符合条件。
    快捷键 Ctrl+T 一键把数据变成表格，排序筛选全自动。

  • ▶Word — 文档排版与域代码

    Word 不光是打字。按 Ctrl+F9 插入域代码可以实现自动编号、动态引用标题。论文、报告排版用它就对了。

  • ▶Markdown — 纯文本写作格式

    Markdown 是在任何平台都能保留同样排版的简单写法。两个星号包裹文字即可**加粗**，连续三个#号加空格就是三级标题。GitHub、知乎、OBS 里全通用。

  • ▶Git — 版本控制工具

    你可以用 Git 把你的每一份文档修改记录永久保存，而且随时能退回去。任何写项目和作文档的人都可以靠三部曲上手：git add . → git commit -m "备注" → git push。
