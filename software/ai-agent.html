AI Agent — 零基础快速上手指南

不管你是不是技术人员，只要会打字，这一篇看完就能自己玩转 AI Agent。

  • ▶1️⃣ 什么是 AI Agent

    通俗理解：AI Agent 就是一个"会用工具的 AI 助手"。它不光会聊天，还会打开网页自动点击、调用软件、自动把你的密码/开关配通……然后自己做一系列任务，据结果自动调整。

    核心区别：AI 聊天 vs AI Agent

    普通的 AI 只输出文字。AI Agent 做行为。比如你告诉 AI："帮我把桌面上所有 PDF 压缩成 Zip"，Agent 会直接调用打包软件，然后交给你文件，而不只是给你出现文件的路径代码。

  • ▶2️⃣ 市面上能立刻用的 Agent 产品

    💻 OpenAI Codex CLI

    这是什么：一个命令行互动助手，让你直接边说边让 AI 操作电脑中的文件、日记代码、网页。目前 Windows/Mac 都支持，免费基础流量即够日常。

    适合使用者程序员、AI入门同学
    能力读写磁盘、自动跨文件修改代码、可打开浏览器检查页面、自动调试
    感受把 "不知咋做" 说清楚，它自己去完成

    ☁️ Claude Code

    这是什么：基于 Anthropic 的 Claude 的终端 AI Agent 工具。行为和 Codex 类似，特别的风格——更口语化，容易被非英语母语的人理解。

    特点集成 GitHub/Git操作、可自动创建 PR、测试、发 Issue——一次搞定。

    🤖 其他重要 Agent 工具

    Cursor带 AI 全自动补全的代码编辑器
    Windsurf专门对复杂文件导航有良好维护
    ChatGPT + 插件点击官方创建的工具交互，让 ChatGPT 连接各种服务——这是所有 Agent 的核心模型
  • ▶3️⃣ API Key 是什么？怎么拿？

    🔑 API Key = 你的数字身份证

    很多人一听“API key”就茫然——其实你只需这样理解：

    API Key 就是一个独一无二的长密码。把你的 Agent 工具提交该密钥给 AI 服务端——对方检查你的资格和余额，再让 AI 干活。缺了它就什么都调不了。

    📋 从哪能免费拿到 API Key？

    1. 打开 platform.openai.com
    2. 登入后点 "Create new secret key"。
    3. 复制生成的长串字符串（sk-proj-xxxxxxxx 开头）。
    4. 贴在你要用的 Agent 设置中。
    5. 充值 5 美元即可用你。日常试用几百次沟通只需很少费用。
    绝对不要跟任何人分享 API Key —— 包含你付款信息的动态。别人拿到等于花你的钱。
  • ▶4️⃣ Agent Rules / Rule 是什么意思

    📜 Rule（规则）= 你给 Agent 写的法律规定

    每创建 Agent 实例时你可以在其设置里放一条或多条 “Rule”—— 个性化指令明文 它必须时刻遵守。比如：

    你写下的 Rule效果
    永远用中文输出回答Agent 不能突然变成英文
    每项写入后都做 git commit自动提供安全性质的回滚能力
    不要运行 rm 命令防止新手误删文件
    每次 30 分钟测试一次Agent 定时积极状态汇报

    另一种 Rule：定期自动执行

    你甚至可以告诉 Agent：「每天早上 7 点抓取我的每日待办，然后自动存档为 Markdown。」它从 Rule 打开就开始了。

  • ▶5️⃣ Skill（技能）是什么？怎么用？

    🎯 Skill = 一套专属的说明书

    很多 AI Agent 会有一个概念叫做 Skill—— 你给一组专业指文化塞进 Agent 里，它就有了特殊能力。本质上是一份专业知识教程放上去就能直接调用那些知识。

    目的：你用零知识 —— 只要装上一个 skill，Agent 自动会处理那一类问题。

    实际例子

    Skill 名称作用你无需会
    📦 PDF 处理直接让 Agent 读取 PDF 内容、转图片或输出文本。不需要懂 PDF 结构
    🧾 Excel 专题生成带公式的工作簿、自动化报表。不需要刻公式
    📖 Github PR 审阅自动发现引名异常等不足。不需掌握 GIT 差异对比
  • ▶6️⃣ 零基础 10 分钟上手四步法
    1. 装一个 Agent：搜索 OpenAI Codex 打开官网下载安装（客户端/命令行）。
    2. 拿一个 API Key：去平台—创建—复制——贴到 Agent 设置中。
    3. 设置第一条 Rule：在设置 区 Rule 里写上“always answer in Chinese, keep answers under 200 words”测试。
    4. 给你第一个任务：对 Agent 说：“帮我新建一个电脑硬件笔记 html 页面、包含 CPU 表格、并风格暗色主题。” Agent 自动创建、保存到指定目录、预监。
    5. 读错就回头改：出错时告诉 Agent "刚才挂了，请再试"—— Agent 会自动改思路。
    6. 再附加 Skill："为电脑硬件库添加相关 PDF 阅读能力" ——下载一个 Adobe 相关或自己设置文档。
  • ▶🧠 更进一步: 模型训练与 RAG

    Token 是什么

    AI 看清的最小单位，相当于一个字或词根。每次提问与回答都会消耗 token。

    RAG — 给 AI 更有实料的知识

    你把本地 PDF/书籍丢进向量数据库 (Chroma)，AI 先从中找到最相关段落，再生成有据可查的回答。（不对让你数据入幻觉）
