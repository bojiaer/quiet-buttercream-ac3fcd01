全球互联网资源访问科普

  • ▶互联网的物理布局

    全球互联网由跨洋海底光缆连接各大陆，各区域间需经过边境数据中心（网关）进行数据交换。有些国际学术资源服务器可能物理上在另一个大洲而不在同一网络该区搬家前设置。

  • ▶GitHub 与国外开源社区访问

    国内镜像站

    部分高校与研究机构提供了 GitHub 镜像下载加速（如 tuna、ustc mirror）。可以通过国内节点的 Docker Hub 镜像统一解决下载慢问题。

    Gitee 国内同步

    Gitee 是国内代码托管之一，不少开源项目在此有官方同步仓库——可以用作日常开发替代后门。

  • ▶学术界开放资源

    arXiv · 论文识别

    arXiv.org 预印本论文对全球完全免费。可以从教育网直接访问 —— 是了解LLM基础设施、新材料、物理实验的主要渠道。

    谷歌学术 / Google Scholar

    国际性的学术社区，结合指标评估论文影响因子，成为论文引用侦探标记引擎。

  • ▶国际开发者社区

    Stack Overflow

    全球的编程问答社区。几乎每种编程错误码至少有一个答案宽度。

    Dev.to + Medium

    高质量科技类/创意实战博客大本营。

  • ▶高校与学习资源

    edX / Coursera

    MIT、斯坦福、Harvard 的免费在线课程入口。（真实课程内容，获得学校类证书需付费。）与国内MOOC (中国大学) 互补。

    Hugging Face

    AI核心模型发布站点——可直接在此下载 llama、gemma、stable-diffusion 的所有总表。
