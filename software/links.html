实用网址推荐

  • ▶硬件工具类

    🛠 图吧工具箱 — 官方网站

    一站式电脑硬件检测合集 —— CPU-Z、GPU-Z、AIDA64、CrystalDiskMark 都打包在一起，装机验机必备。

    🔗 https://www.tbtool.cn

    📊 游戏加加 — 游戏帧数监控与优化

    游戏内叠加显示 CPU/GPU 温度、帧数、延迟时间，自动生成性能报告。

    🔗 https://gamepp.com

    🖥 CPU-Z / GPU-Z 官网

    查看你当前电脑所有硬件细节——型号、缓存大小、BIOS 版本、显存通路。

    🔗 https://www.cpuid.com

    📏 HWiNFO — 深度硬件监护

    监控每项主电压温度、详细传感器读数、风扇速度。超频或排查异常温度必备。

    🔗 https://www.hwinfo.com

  • ▶游戏平台与工具类

    🎮 Steam — 全球最大游戏平台

    正版游戏购买下载，创意工坊模组浏览，内置好友聊天 + 截图库。

    🔗 https://store.steampowered.com

    🟠 Epic Games Store

    每周送免费正版游戏，不定期独霸大作。

    🔗 https://store.epicgames.com

  • ▶显卡驱动官方下载

    🟢 NVIDIA 驱动下载

    GeForce Game Ready 驱动 + NVIDIA App 官方页面，自动优化游戏设置。

    🔗 https://www.nvidia.com/geforce-experience

    🔵 AMD Adrenalin — Radeon 官方驱动

    整合了驱动更新、游戏设置、性能监控和录像功能，等同于 Radeon 的"控制中心"。

    🔗 https://www.amd.com/en/support

    🔷 Intel 驱动与支持助手

    自动检测你的 Intel 集成显卡、Wi-Fi / 蓝牙芯片驱动版本，一键下载最稳定的 WHQL 驱动。

    🔗 https://www.intel.com/support/detect

  • ▶系统调试工具类

    BlueScreenView / WinDbg Preview

    解析蓝屏 .dmp 文件，精准找出崩溃驱动程序。

    🔗 https://www.nirsoft.net/blue_screen_view

    Rufus — 纯净 U 盘制作工具

    写入 ISO 即生成 UEFI 启动盘，非常小巧高效。

    🔗 https://rufus.ie
