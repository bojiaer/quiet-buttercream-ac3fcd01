Windows 激活方法 — 命令行

  • ▶数字许可证激活（Win10 / Win11）

    什么是数字许可证

    数字许可证（Digital License）绑在你的设备硬件上，不需要输入产品密钥。做过一次激活以后，重装系统也能自动重新激活。

    操作步骤

    1. 以管理员身份打开 CMD 或 PowerShell
    2. 安装对应版本的通用密钥（GVLK）：
      slmgr /ipk W269N-WFGWX-YVC9B-4J6C9-T83GX
      （上面是专业版密钥，其他版本去微软官方查"GVLK Windows"）
    3. 联网状态下运行：
      slmgr /ato
    4. 看到弹出窗口提示"已成功激活"就完成了
    注意：这需要电脑能正常连接到微软的激活服务器。如果你的网络无法访问微软服务器，这个方法会报错。
  • ▶KMS 批量激活

    KMS 是什么

    KMS（Key Management Service）是微软对大客户的批量授权方式。客户端定期向 KMS 服务器报到，每次激活有效期 180 天，服务器在任期内自动续签。

    操作步骤

    1. 管理员 CMD 输入：
      slmgr /skms kms.xxxx.xxx
      （把 xxx 部分换成可用的 KMS 服务器地址）
    2. 再输入：
      slmgr /ato
    3. 看到"已成功激活"即完成
  • ▶查看激活状态 / 过期时间

    常用 slmgr 命令

    命令作用
    slmgr /xpr查看当前激活/期限（弹窗）
    slmgr /dli显示授权详细（控制台）
    slmgr /dlv列出所有授权信息含最后登录/激活次数
    slmgr /ato强制重新联网请求激活验证
    slmgr /skms [servert域名]指定 KMS 服务器
