Windows 常见错误代码与蓝屏速查手册

常规提示：运行命令前请将 cmd/PowerShell 以管理员身份打开。操作注册表编辑器前建议先导出备份分支。
  • ▶蓝屏错误 (BSOD) — 所有常见停止代码

    0x0000007B — INACCESSIBLE_BOOT_DEVICE

    硬盘控制器模式变更（IDE ↔ AHCI/RAID）导致启动设备不可访问。

    1. 重启进 BIOS → Storage Configuration → 切换 SATA 模式。
    2. 进 PE 系统后运行：bootrec /fixmbr bootrec /fixboot bootrec /rebuildbcd

    0x000000EA — THREAD_STUCK_IN_DEVICE_DRIVER

    显卡驱动陷入死循环，屏幕卡住几秒后蓝屏。

    • 开机 F8 进安全模式 → DDU 工具卸载所有显卡驱动残余。
    • 从官网下载 WHQL 认证驱动重装。
    • 拔掉独显靠核显——先把范围缩小成卡死还是卡坏。

    0x00000050 — PAGE_FAULT_IN_NONPAGED_AREA

    系统尝试访问一个不存在的虚拟地址页 → 99% 故障是内存坏根、坏驱动或硬件识别错误。

    • 拔掉至少一根内存条仅留一条测试。
    • sfc /scannow 修系统文件。
    • 事件查看器 → 筛选 Kernel-Power 事件。

    0x0000001A — MEMORY_MANAGEMENT

    通常为 RAM 显存错误或系统内存管理程序异常。

    • memtest86 完全测试 2 小时。

    0x000000D1 — DRIVER_IRQL_NOT_LESS_OR_EQUAL

    驱动试图在非许可 IRQL 访问物理内存。

    • 拔除非必要外设 → 看哪个驱动崩溃或通过蓝屏查看对应 .sys 文件名。

    0x0000003B — SYSTEM_SERVICE_EXCEPTION

    网络安全/系统文件损坏导致。

    • DISM 修复：DISM /Online /Cleanup-Image /RestoreHealth。

    0x0000009F — DRIVER_POWER_STATE_FAILURE

    系统从睡眠/休眠唤醒时驱动出错。Intel 英特尔无线网卡驱动高度可能。

    • 更新无线网卡驱动 + 测唤醒。

    0x00000124 — WHEA_UNCORRECTABLE_ERROR

    硬件故障系统报告（CPU 或电压不稳）。

    • 清 BIOS 缺省，若超频先清回默认。

    0x00000D1 — IRQL Drive...重复→算旧版本含其他关联。

    通过 kd或 WinDbg 确认准确错误Source。

    0xC000021A — STATUS_SYSTEM_PROCESS_TERMINATED

    信任的系统进程Winlogon或CSRSS被不兼容的第三方软件干掉。

    • W进安全模式→ msconfig 关最近启动。

    CRITICAL_PROCESS_DIED

    关键系统进程不存在了修复——pe内还原或重置。

    KERNEL_SECURITY_CHECK_FAILURE

    内核模块的指针损坏，双驱动冲突高度可能——卸载虚拟网卡／杀毒。

  • ▶启动 / 程序错误

    无法启动此程序，因为计算机中丢失 xxx.dll

    DirectX/VC 运行库被错删。

    • 管理员 PowerShell：sfc /scannow
    • 安装 DirectX 9.0c 最终用户运行时 + Visual C++ AIO 安装包。

    错误 0x80070002 / 0x80070003 — 找不到文件

    Windows Update 或服务期Down缓存坏。

    • cmd 停止 wuauserv → 删除 C:\Windows\SoftwareDistribution\ → 重启 wuauserv。

    0xc0000225 — 找不到启动设备

    BCD 表有误。

    • PE 系统中执行：bootrec /rebuildbcd

    0xc000000F — Windows 启动管理器错误

    BCD 损坏，蓝屏出现该 CODE 一般直接提示进入恢复环境。

    0x80004005 — 未指明的通用错误

    RDP / 权限/ DCOM 原因→检查防病毒软件强制。

  • ▶网络连接故障

    DNS 服务器未响应

    • 网络适配器属性 → IPv4 → 推敲 DNS 为 1.1.1.1 / 223.5.5.5。
    • 运行 ipconfig /flushdns。

    ERR_CONNECTION_RESET / 连接已重置

    代理/VPN 或浏览器缓存问题 → netsh winsock reset。

    ERR_NAME_NOT_RESOLVED / 无法解析服务器地址

    理论→直连的 VPN 的设置——断开代理试。

    0x800CCC0F — 邮件端口出站被挡

    防火墙 25 端口异常。

  • ▶Windows Update 专属错误

    0x80070020 — 程序正在使用

    杀毒临时锁文件→清卸载 SoftwareDistribution。

    0x80072EE2 / 0x80072F8F — 时间与服务器不同步

    消除Windows时间 → 对时 time.windows.com。

    0x800F0922 — 太小的系统保留分区

    将 System Reserved 扩至 500MB。

    0x8024200B — 更新下载损坏

    暂停更新然后重新触发。

  • ▶存储路径错误

    0x800703EE (文件污染)

    外设没有安全弹出损坏;

    0x8007001F — 设备未运行完全

    PC 不能读外部硬盘，急用仅此一个分区便不再了。
