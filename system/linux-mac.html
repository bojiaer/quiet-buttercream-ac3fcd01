Linux 与 macOS 入门科普

1. Linux 发行版定位与选择

发行版定位适合谁包管理方式
Ubuntu主流入门、软件库庞大新手 | 开发 | 日常办公apt
Linux MintCinnamon 桌面环境继承 Win 体验刚从 Windows 迁出的用户apt
Fedora追踪最新开源技术喜欢尝鲜和容器/Kubernetes 的开发者dnf

2. 终端常用姿势

# 系统更新
sudo apt update && sudo apt upgrade -y    (Ubuntu/Mint)
sudo dnf update -y                         (Fedora)

# 服务管理（systemd）
sudo systemctl start nginx
sudo systemctl enable ssh

# 磁盘查看
lsblk -f
df -h

3. WSL2——在 Windows 中运行真实 Linux 内核

Windows Subsystem for Linux 2 为 Windows 用户提供了原生 Linux 终端，支持 Docker 和 CUDA 加速，可通过 wsl --install 一键部署 Ubuntu。文件互通在 /mnt/c 目录完成。

4. macOS 系统

macOS 基于 Darwin 内核，是 UNIX 认证系统。这使得原生终端（zsh）可以运行常见 Linux 命令。Homebrew 是类 Linux 包管理器，让 Python、Git、VS Code 等安装变得更快。Time Machine 快照备份仅需外接硬盘。

5. 跨平台差异化

  • Linux 文件路径区分大小写。
    Windows 可无视。
    macOS 默认也区分+支持 APFS snapshot 版本控制。
  • PATH 环境变量熟悉下 /usr/local/bin 的位置——许多 .js 解释器通过它加载。
